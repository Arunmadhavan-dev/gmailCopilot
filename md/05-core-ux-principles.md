# Core UX Principles

## Floating Assistant First

Inbox Copilot behaves like:
- ChatGPT inside Gmail
- Cursor for inboxes
- conversational command center

NOT:
- permanent sidebar
- dashboard
- admin panel

---

## Invisible Until Needed

Default state:
- collapsed
- minimal
- ambient

---

## Fast Interaction Loops

Goals:
- assistant launch < 100ms
- interaction latency < 50ms

---

## Contextual Intelligence

Assistant adapts to:
- current Gmail tab
- selected thread
- inbox category
- recent actions
