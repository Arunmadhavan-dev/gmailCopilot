# Product Principles

## Principle 1 — Conversational First

Users should never need:
- Gmail operators
- manual filtering
- inbox rule configuration

The system translates natural language into actions.

---

## Principle 2 — Human In The Loop

AI must never execute destructive actions automatically.

All destructive actions require:
- previews
- affected item counts
- explicit confirmation

---

## Principle 3 — Gmail Native

The product lives inside Gmail using a floating conversational assistant.

---

## Principle 4 — Fast Feedback Loops

Interactions should feel immediate.

Latency targets:
- UI interactions < 100ms
- search results < 3s

---

## Principle 5 — Transparency

Users must always understand:
- what AI interpreted
- what query was generated
- what emails are affected
- what actions will happen
